# Development

```bash
git clone https://github.com/kebasaa/kobopatcher
cd kobopatcher
python3 -m venv .venv && .venv/bin/pip install -e '.[dev]'
.venv/bin/pytest
```

- Tests that need firmware files skip themselves when the files aren't there.
  `KOBOPATCHER_TEST_ROOTFS` points the ELF tests at an extracted 4.38.23429
  rootfs.
- [tools/parity](../tools/parity) contains the differential tests against Go
  kobopatch, which produced [parity.md](parity.md); how to rerun them
  is described there.
- Standalone executables are built with PyInstaller by the `release` workflow
  (`.github/workflows/release.yml`).
- The patch sets are generated by `tools/make_patchset.py` and published by the
  `patchsets` workflow (see [usage.md](usage.md#publishing-patch-sets)). The
  `test-patches` workflow applies every patch of every set to kobopatch-testdata.
- The guided mode's tests run against a local HTTP server and a fake Kobo folder
  (`tests/test_guided.py`); no test touches the network or a real Kobo.
